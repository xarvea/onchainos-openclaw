# ADR-0001 — Chain: Solana

**Status:** Accepted

## Konteks
Perlu chain dengan biaya transaksi rendah, finality cepat, ekosistem NFT matang,
dan dukungan standar terbuka (Metaplex).

## Keputusan
Solana (mainnet-beta), mulai dari devnet untuk pengembangan.

## Alternatif
- Ethereum L2 — biaya lebih tinggi, ekosistem NFT kuat tapi gas mahal untuk mint massal.
- Base — emerging, ekosistem NFT belum matang.

## Konsekuensi
Terikat ekosistem Solana; leverage Metaplex Core/Candy Machine; indexer pakai DAS.
